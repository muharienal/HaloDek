HaloDek v38: modul inventaris pindah ke aplikasi "Inventaris Umum & IT".
Jika Anda menimpa folder lama dengan isi zip ini, HAPUS file/folder berikut
(mereka sudah tidak dipakai dan akan membuat error/tes gagal bila tertinggal):

app/Http/Controllers/Admin/InventoryController.php
app/Http/Controllers/Admin/LocationController.php
app/Models/InventoryItem.php
app/Models/InventoryCategory.php
app/Models/Location.php
resources/views/admin/inventory/        (seluruh folder)
resources/views/admin/locations/        (seluruh folder)
tests/Feature/TeamAndInventoryTest.php  (diganti tests/Feature/TeamTest.php)

Perintah cepat (Git Bash, dari folder HaloDek):
  git rm -r app/Http/Controllers/Admin/InventoryController.php app/Http/Controllers/Admin/LocationController.php app/Models/InventoryItem.php app/Models/InventoryCategory.php app/Models/Location.php resources/views/admin/inventory resources/views/admin/locations tests/Feature/TeamAndInventoryTest.php

Lalu: composer dump-autoload && php artisan migrate && php artisan view:clear && php artisan config:clear
Tabel database inventaris lama TIDAK dihapus oleh migrasi (dibaca oleh perintah impor di aplikasi Inventaris).
